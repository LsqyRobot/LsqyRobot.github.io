约定先写清楚，姿态才可复现

本页定义 q_WB 为机体系 B 到世界系 W 的旋转映射，采用 Z-up、XY 地面。默认纯旋转时 OW 与 OB 重合；开启平移后，t_WB 给出 OB 在 W 中的位置，而矩阵 R 的三列仍是 B 的三根单位轴在 W 中的坐标。

01 / ORDER

随动轴 ZYX

先绕初始 Z 轴 yaw，再绕更新后的 Y′ 轴 pitch，最后绕更新后的 X″ 轴 roll。组合为 R = Rz(yaw) · Ry(pitch) · Rx(roll)。

02 / QUATERNION

w 在最前

页面使用 Hamilton 四元数 q = [w, x, y, z]。q 与 -q 表示同一旋转；输入会先归一化。

03 / B TO W

分量不变，向量转动

固定 v_B 时，v_W = R_WB v_B。金色箭头跟随机体系转动，彩色折线表示它沿 x_B / y_B / z_B 的三个分量。

04 / W TO B

向量不动，只换坐标

固定世界中的几何向量时，v_B = R_WB^T v_W。金色箭头不动，但机体系转动会让三个坐标读数变化。

05 / PATH

一段轴角与三段 ZYX

合成轴角沿相对四元数的一根固定轴走最短路径；等价 ZYX 则依次走 Z、Y′、X″ 三段。二者终点相同，中间路径通常不同。

06 / LIMIT

欧拉角有奇异性

pitch 接近 ±90° 时会出现万向节锁，反算出的 roll / yaw 组合不唯一；此时三段动画只展示其中一组等价分解。

07 / SE(3)

向量与点要分开

自由向量只做 v_W = R_WB v_B；点与坐标系原点则做 p_W = R_WB p_B + t_WB。统一进度只是为了观察方便，不改变这两类对象的数学区别。
