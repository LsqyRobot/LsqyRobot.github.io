约定先写清楚，姿态才可复现

不同库对四元数顺序、坐标系和欧拉角内禀 / 外禀旋转的定义可能不同。这里的结果适用于右手系、主动旋转和 ZYX 顺序。

01 / ORDER

ZYX 顺序

先绕自身 X 轴 roll，再绕更新后的 Y 轴 pitch，最后绕更新后的 Z 轴 yaw。组合矩阵为 R = Rz(yaw) · Ry(pitch) · Rx(roll)。

02 / QUATERNION

w 在最前

页面使用 q = [w, x, y, z]。四元数和它的相反数表示同一个旋转；输入会先归一化再参与计算。

03 / LIMIT

欧拉角有奇异性

pitch 接近 ±90° 时会出现万向节锁，反算出的 roll / yaw 组合不唯一。需要连续姿态时，优先保存四元数。
