  • [x] 优化四元数动画为“按轴角分解/关键时刻可视化”的清晰显示。
  • [x] 增加三实体展示：

    • [x] 当前机体系 B
    • [x] 虚拟目标 B*
  • [x] 补齐欧拉角阶段标记（1/3 / 2/3 / 3/3）与四元数轴角进度提示。
  • [x] 增加“固定轴 vs. 分段轴”行为说明，避免把两种中间路径混为一谈。
  • [x] 将世界系 W 与机体系 B 改为共原点叠加展示，画出旋转轴、角度弧与向量分量。
