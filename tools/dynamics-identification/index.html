动力学
参数辨识

上传固定基机器人 URDF 与关节实验数据，由 Docker 容器中的 C++ 求解器构造动力学回归矩阵并估计参数。当前实现面向 revolute、continuous 与 prismatic 关节；输入只发送到本机 127.0.0.1:4010 的计算服务。
