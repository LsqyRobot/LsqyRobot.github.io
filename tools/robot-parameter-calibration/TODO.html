工业机器人标定页：本机启动与线上降级

本文件是 /tools/robot-parameter-calibration/ 运行时体验的专项契约。C++ 算法与输入格式仍见 apps/robot-calibration/README.md，容器与 helper 权限边界见 docker/robotics-workbench/README.md。

已实现（2026-09-13）

  • [x] 非回环主机名一律进入线上静态模式；即使误写 robotics-runtime-mode=local，也不能让公网页面探测访问者的 127.0.0.1:4010/4011。
  • [x] 本机页面区分“服务已运行 / Docker 未启动 / 服务启动中 / 服务停止中 / 服务异常”，线上页面显示“当前为线上版本”。所有状态都有可读文本，不只依靠颜色或动画。
  • [x] server/robotics-helper.mjs 只把固定的 status/start/logs/stop 路由映射到 compute-status、compute-up、compute-logs、compute-down；没有任意 action、命令、参数或 Compose 路径入口。
  • [x] helper 固定绑定 127.0.0.1:4011，严格校验 Host、精确本地 Origin、方法、JSON media type/body、请求大小和单 job 并发；子进程不经过 shell，输出有界。
  • [x] 页面提供启动、检查、日志和带二次确认的停止入口；显示首次构建、轮询健康、超时和结构化错误，并在 helper 缺失、权限/端口/浏览器本地网络访问失败时展开复制命令。
  • [x] 线上仍可阅读全部参数说明并载入静态 DH 示例；ABB 全闭环、预检和求解按钮保持禁用且标注“仅本地计算”。
  • [x] 启动 Docker 不刷新页面；当前标签页通过 sessionStorage 保存任务模式、模型约定与非文件参数。浏览器安全模型不允许跨刷新恢复用户选择的本地 File 对象，页面启动过程本身不会清空它们。
  • [x] calibration-serve <port> 在同一前台会话启动 helper 和 Hexo；正常退出或 Ctrl-C 时清理 helper，helper 端口占用时直接报错且不终止未知进程。已有 Hexo 可配合 compute-helper <site-port> 单独运行。

验收矩阵

  • [x] 自动化：npm run calibration:runtime:test 的 20 项 helper 路由/安全/并发/有界输出、执行型 online/stopping/结构化错误 controller，以及 DOM/持久化源码契约测试通过；npm run server:test 的 28 项服务测试也通过。
  • [x] API：真实默认 :4010 上的 11 项聚合健康、CORS、动力学、标定、FK、IK、独立 FK 回放、轨迹及 API-only 数值 smoke 通过；伪造非回环 Host 的请求返回 421。
  • [ ] 本机浏览器：Docker 关闭 → 页面显示未启动 → 点击启动 → 健康 → ABB/标定/FK/IK/轨迹成功；参数刷新恢复；日志可读；停止二次确认；异常可重试。
    • 已完成同协议的真实 HTTP 生命周期、日志、端口冲突与参数持久化实现验证；当前 Codex in-app Browser 没有可用实例，不能把这些证据冒充为点击/截图验收。
  • [ ] 线上降级浏览器：用解析到同一本地构建的非回环 hostname 打开页面，确认 :4010/:4011 请求数为 0、无无限 loading、计算控件禁用、静态示例和本地命令可用。
    • 执行型 VM 已覆盖公开 controller 的 refresh/start/stop/logs 并确认 loopback 请求数为 0；仍待真实浏览器复验。
  • [ ] 视觉：约 1440×1000 与 390×844 截图无横向溢出、遮挡或仅靠动画表达的状态；prefers-reduced-motion 下状态仍可读。
  • [x] 浏览器验收入口：npm run calibration:browser:verify 调用真实 Chrome/CDP，在两档视口检查本地/线上状态与横向溢出，并将线上请求证据和截图写入指定目录；当前环境没有可用浏览器实例，因此脚本只完成语法检查，不能替代上面三项实跑结果。
  • [x] 站点：Node 24 下 clean Hexo build（1794 files）、生成路由/脚本/样式契约、JS/Bash 语法和 git diff --check 通过。

明确边界

  • helper 与计算 API 都是当前用户的本机开发工具，不是公网服务；没有账号、TLS 或多用户授权，不能绑定局域网地址或通过反向代理公开。
  • 停止 Workbench 会同时影响动力学辨识、机器人标定/FK/IK 和轨迹规划页面，因此 UI 必须保留影响说明和二次确认。
  • 本项不替代原生 x86_64、长期压力、真实测量设备或实机安全验证；这些跨架构/工业验收仍在顶层 Docker 遗留项中维护。
