Portable by construction

MuJoCo 后端只需要 Docker

Python、MuJoCo、OSMesa、C++ worker、ONNX Runtime、策略权重和机器人模型均由镜像构建。macOS 与 Ubuntu 使用相同 Compose 命令，不依赖宿主机仿真环境。

  • 6首批机器人
  • 3模型类别
  • 0宿主机仿真依赖

UR5e 与 Panda 使用末端 IK 和逐关节目标控制；Go2 策略会话使用独立的 ONNX CPU 适配器，通过 vx、vy、wz 指令驱动。模型、策略与控制器各自遵循显式接口，后续可继续接入其他开源策略、轨迹和传感器曲线。
