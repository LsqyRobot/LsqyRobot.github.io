操作说明与致谢

点击关节卡片选择关节，使用滑条或画布拖动调整。画布获得焦点后，方向键微调，Home / End 跳到关节限位，空格切换播放。

这是一套运动学与建模检查工具，不执行物理仿真、动力学控制或精确碰撞检测。显示 Collision 几何也不等于完成碰撞验收。

页面由主机 Hexo 提供；URDF、mesh 解析与 WebGL 在浏览器本地完成。本工具不需要启动 Docker 计算服务，也不会将模型文件上传。

界面与交互参考 Garrett Johnson 的 URDF Viewer 原示例。感谢 urdf-loader（Apache-2.0）与 Three.js（MIT）。本站保留本地教学模型，没有复制完整 ATHLETE 演示及其资源。
