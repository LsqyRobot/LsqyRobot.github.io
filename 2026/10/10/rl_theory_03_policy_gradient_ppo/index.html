强化学习理论 03：从策略梯度到 Actor–Critic、GAE 与 PPO

文章目录

价值型控制想比较每个动作的 QQQ。但四足机器人一次输出十几个连续量，不能把所有组合都枚举一遍。另一个思路是直接学习可微策略：让带来较好结果的动作更容易出现，让较差的动作更少出现。

这一章依次解释四个桥梁：回报如何变成梯度，critic 为何能帮 actor，GAE 怎样组合证据，PPO 为什么限制局部更新的获益。 代码中的张量细节留给站内已有的 PPO 训练闭环长文。

一、策略梯度：不对环境求导，也能调整动作分布

对有限回合，取目标

Jγ(θ)=Eτ∼πθ[∑t=0T−1γtrt].J_\gamma(\theta)=\mathbb E_{\tau\sim\pi_\theta} \left[\sum_{t=0}^{T-1}\gamma^t r_t\right]. Jγ​(θ)=Eτ∼πθ​​[t=0∑T−1​γtrt​].

轨迹概率由初始状态、每步策略概率与环境转移概率相乘得到。假设环境和初始分布不依赖 θ\thetaθ，利用 ∇p=p∇log⁡p\nabla p=p\nabla\log p∇p=p∇logp，轨迹对数概率的参数梯度就只剩策略各步的项。再利用“当前动作不改变已经发生的奖励”，得到回报到达形式：

∇θJγ=E[∑t=0T−1γt∇θlog⁡πθ(at∣st)Gt],Gt=∑k=0T−t−1γkrt+k.\nabla_\theta J_\gamma= \mathbb E\left[\sum_{t=0}^{T-1}\gamma^t \nabla_\theta\log\pi_\theta(a_t\mid s_t)G_t\right], \qquad G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k}. ∇θ​Jγ​=E[t=0∑T−1​γt∇θ​logπθ​(at​∣st​)Gt​],Gt​=k=0∑T−t−1​γkrt+k​.

这里保留了 γt\gamma^tγt：它来自所定义的折扣目标。当 γ=1\gamma=1γ=1 且回合有限时可以省略；其它资料也可能把权重放进折扣状态访问分布。实际 PPO 常对 rollout 样本均匀优化 surrogate，不能把这些不同的采样权重不加说明地当成同一个精确等式。

直觉上，∇log⁡π\nabla\log\pi∇logπ 给出“怎样增加本次动作的对数概率”的方向，回报决定朝这个方向推多大。它不要求直接对接触动力学、碰撞或仿真器求导；但仍需采样环境来得到奖励证据。有限样本的噪声也没有因此消失。

二、baseline 与 advantage：好是相对于什么

如果每条轨迹的回报都很大，直接用 GtG_tGt​ 会让梯度波动大。减去只依赖当前状态、与当前动作无关的 baseline b(st)b(s_t)b(st​)，不会改变策略梯度的期望：

Ea∼π[∇θlog⁡πθ(a∣s)b(s)]=b(s)∇θ∑aπθ(a∣s)=0.\mathbb E_{a\sim\pi}[\nabla_\theta\log\pi_\theta(a\mid s)b(s)] =b(s)\nabla_\theta\sum_a\pi_\theta(a\mid s)=0. Ea∼π​[∇θ​logπθ​(a∣s)b(s)]=b(s)∇θ​a∑​πθ​(a∣s)=0.

连续动作时把求和换成积分，在相应正则条件下结论相同。取 b(s)=Vπ(s)b(s)=V^\pi(s)b(s)=Vπ(s)，可以把权重理解成“这个动作比当前状态的平均选择好多少”。01 中的理想优势为

Aπ(s,a)=Qπ(s,a)−Vπ(s).A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s). Aπ(s,a)=Qπ(s,a)−Vπ(s).

在两步任务里，forward 的即时奖励为 −1-1−1，但优势为 +0.8+0.8+0.8，因此应增加它的选择倾向。baseline 不改变期望的证明，并不表示任何近似 critic、任何 bootstrapped advantage 都无偏。

三、Actor–Critic：一个负责选择，一个负责估值

actor 用 θ\thetaθ 表示 πθ\pi_\thetaπθ​，critic 用 ϕ\phiϕ 表示 VϕV_\phiVϕ​ 或 QϕQ_\phiQϕ​。一种常见 on-policy 实现是：

  1. 用旧策略与环境交互，保存动作、奖励、旧 log-prob 和旧 value；
  2. 从这一批轨迹构造 A^t\hat A_tA^t​ 与 critic 的训练目标 R^t\hat R_tR^t​；
  3. actor 根据优势更新策略，critic 根据目标拟合价值；
  4. 再采新数据，重复闭环。

critic 常见损失为 LV=E[(Vϕ(st)−R^t)2]L_V=\mathbb E[(V_\phi(s_t)-\hat R_t)^2]LV​=E[(Vϕ​(st​)−R^t​)2]。actor 的简单梯度代理损失可写成 −log⁡πθ(at∣st)A^t-\log\pi_\theta(a_t\mid s_t)\hat A_t−logπθ​(at​∣st​)A^t​，优化器做最小化。这里表示常见的均匀样本代理；若要严格对应第 1 节的折扣目标与逐回合求和，应保留 γt\gamma^tγt 权重或采用相应的折扣状态访问采样。actor 更新时把估计优势作为固定权重，停止其梯度（detach）；critic 的监督目标也要按算法固定。 否则不再是前述 baseline 推导描述的更新。

在部分可观测机器人任务里，actor 可能接收 oto_tot​，critic 在训练时接收额外状态信息。不要把同一字母 sss 在代码里自动等同于完全相同的输入张量，见输入输出维度笔记。

δt=rt+γbtVold(st+1final)−Vold(st),\delta_t=r_t+\gamma b_tV_{\rm old}(s_{t+1}^{\rm final})-V_{\rm old}(s_t), δt​=rt​+γbt​Vold​(st+1final​)−Vold​(st​),

这就是有限片段常用的反向递推。在连续无边界的片段上展开：A^t=δt+γλδt+1+(γλ)2δt+2+⋯\hat A_t=\delta_t+\gamma\lambda\delta_{t+1}+(\gamma\lambda)^2\delta_{t+2}+\cdotsA^t​=δt​+γλδt+1​+(γλ)2δt+2​+⋯。越远的 TD 证据，权重衰减越多。

仍取 s0→−1s1→4terminals_0\xrightarrow{-1}s_1\xrightarrow{4}\mathrm{terminal}s0​−1​s1​4​terminal，γ=0.9\gamma=0.9γ=0.9。本轮旧估计为 Vold(s0)=1.5,Vold(s1)=3V_{\rm old}(s_0)=1.5,V_{\rm old}(s_1)=3Vold​(s0​)=1.5,Vold​(s1​)=3，终止价值为 0：

五、PPO：保留学习方向，限制继续推大的激励

用旧策略采集一批数据后，想做几轮更新来提高利用率。但策略变了，同一个动作的概率也变了。定义同一状态、同一采样动作的新旧概率（连续时为密度）之比：

ρt(θ)=πθ(at∣st)πold(at∣st)=exp⁡(log⁡πθ−log⁡πold).\rho_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\rm old}(a_t\mid s_t)} =\exp(\log\pi_\theta-\log\pi_{\rm old}). ρt​(θ)=πold​(at​∣st​)πθ​(at​∣st​)​=exp(logπθ​−logπold​).

PPO-Clip 最大化

Lclip(θ)=Et[min⁡(ρtA^t,clip⁡(ρt,1−ϵ,1+ϵ)A^t)].L^{\rm clip}(\theta)=\mathbb E_t\left[ \min\left(\rho_t\hat A_t, \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\hat A_t\right)\right]. Lclip(θ)=Et​[min(ρt​A^t​,clip(ρt​,1−ϵ,1+ϵ)A^t​)].

代码中常最小化其负值。取 ϵ=0.2\epsilon=0.2ϵ=0.2，必须分优势正负两种方向看：

不是两个方向越界后都变成平台。 也不是强迫所有 ratio 落在 [0.8,1.2][0.8,1.2][0.8,1.2]；共享网络参数仍会同时改变多个状态/动作。PPO clipping 不是动作限幅，不是 KL 硬约束，也不保证每次真实性能都提高。

通常还联合 value loss 与 entropy bonus；例如最大化策略代理目标和熵，对应最小化 −Lclip+cVLV−cHH-L^{\rm clip}+c_VL_V-c_H\mathcal H−Lclip+cV​LV​−cH​H。各库系数、归约和日志符号不同，先核对实现。熵是分布分散程度的信号，不能单独证明机器人执行了有用探索。

PPO 通常称为 on-policy：用最近策略的数据短期做多个 epoch，之后重新采样。ratio 只比较同一采样状态下的动作分布，不自动修正任意陈旧数据的状态访问分布，因此不能据此无限重放旧经验。

六、连续动作：Gaussian 的 std 与物理 action scale

一种常见策略是对角高斯：

at=μθ(ot)+σθ(ot)⊙εt,εt∼N(0,I).a_t=\mu_\theta(o_t)+\sigma_\theta(o_t)\odot\varepsilon_t, \qquad\varepsilon_t\sim\mathcal N(0,I). at​=μθ​(ot​)+σθ​(ot​)⊙εt​,εt​∼N(0,I).

σ>0\sigma>0σ>0 是标准差，方差是 σ2\sigma^2σ2；若训练的是 log-std，则用 σ=exp⁡(log_std)\sigma=\exp(\mathrm{log\_std})σ=exp(log_std)。均值与标准差可以来自网络，也可以有独立参数，具体以实现为准。

对 DDD 维独立条件高斯，联合 log-prob 是各维之和：

log⁡π(a∣o)=∑i=1D[−(ai−μi)22σi2−log⁡σi−12log⁡(2π)].\log\pi(a\mid o)=\sum_{i=1}^D \left[-\frac{(a_i-\mu_i)^2}{2\sigma_i^2}-\log\sigma_i-\frac12\log(2\pi)\right]. logπ(a∣o)=i=1∑D​[−2σi2​(ai​−μi​)2​−logσi​−21​log(2π)].

PPO 通常比较整组动作的联合密度，而不是给每个关节分别计算一个独立环境决策的 ratio。连续密度也不是“恰好发生这个动作的百分比”。

机器人接口还可能有

qdes=qnominal+kaa.q_{\rm des}=q_{\rm nominal}+k_a a. qdes​=qnominal​+ka​a.

这里 kak_aka​ 是动作到物理关节角的尺度，与策略 σ\sigmaσ 不同。若 ka=0.5 radk_a=0.5\ \mathrm{rad}ka​=0.5 rad、归一化 σ=0.2\sigma=0.2σ=0.2，在没有其它变换的该维接口上，关节目标噪声标准差是 0.1 rad0.1\ \mathrm{rad}0.1 rad。

更新时必须保存采样时用于 log-prob 的动作，用新旧策略评价同一个变量。固定可逆仿射变换的 Jacobian 在 ratio 中抵消；经过 tanh 的分布要处理变量变换；硬 clip 不可逆，不能随意拿 clip 后的值当作原始 Gaussian 样本重算。更详细的 std、entropy、动作饱和与曲线判读见训练曲线诊断。

七、与训练代码的对应

rollout storage 保存采样时的动作、old log-prob、old value 与边界信息；GAE 从后向前递推，并区分 bootstrap 与跨回合传播。actor 使用固定的优势估计，critic 使用按算法构造的目标。KL、clip fraction、固定评估回报与物理约束指标共同解释更新后的效果。这些符号在已有 PPO 代码与交互实验中都有对应的实现位置。
