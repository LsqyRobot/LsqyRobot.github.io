一、AprilTag 是什么

AprilTag 是 University of Michigan APRIL Robotics Laboratory 开源的视觉基准标识（visual fiducial）系统。它的目标不是像普通二维码那样存储大量信息，而是让相机能够稳定地识别一个人工标识，并计算出该标识相对于相机的三维位置、姿态和 ID。

官方软件页对 AprilTag 的定位很直接：

  • 可用于增强现实、机器人、相机标定等任务；
  • 标签可以用普通打印机打印；
  • 检测软件可以计算标签相对相机的精确 3D position、orientation 和 identity；
  • C 语言实现无外部依赖，适合嵌入式设备；
  • 在手机级处理器上也可以达到实时性能。

因此，在机器人系统中，AprilTag 常被用作一个“可控、可重复、可度量”的视觉参考点。

二、为什么机器人系统喜欢用 AprilTag

自然特征点适合 SLAM、VIO 和一般场景感知，但在工程系统里，经常需要一个更确定的视觉锚点。例如：

  • 机器人靠近充电桩时，需要知道充电桩相对自己的精确位姿；
  • 机械臂抓取固定工装时，需要识别夹具或托盘坐标；
  • 多传感器标定时，需要可重复观测的参考平面；
  • 实验验证时，需要稳定的 ground truth 或辅助定位信号。

AprilTag 的价值就在这里：它牺牲了数据容量，换来更强的检测稳定性、更远的识别距离和更高的定位精度。

一句话概括：

QR Code 更像“给人或系统读信息”，AprilTag 更像“给机器人找坐标”。

三、论文脉络

3.1 AprilTag: A robust and flexible visual fiducial system, ICRA 2011

Edwin Olson 在 2011 年 ICRA 论文中提出 AprilTag 系统。论文强调人工视觉标识在可控实验、ground truth、机器人系统快速开发中的价值。

核心特点包括：

  • 使用二维条码风格的 tag；
  • 单张图像即可估计 6 DoF 位姿；
  • 具备快速、鲁棒的线检测系统；
  • 使用更强的数字编码系统；
  • 对遮挡、变形、镜头畸变有更好的鲁棒性；
  • 系统开放，算法细节有完整文档。

这篇论文奠定了 AprilTag 作为机器人视觉标识系统的基础。

3.2 AprilTag 2: Efficient and robust fiducial detection, IROS 2016

2016 年 IROS 的 AprilTag 2 主要关注检测器效率和鲁棒性。论文指出，视觉处理步骤通常是 tag 检测流水线的主要耗时部分，因此即使是小的检测改进，也会显著提升系统速度。

AprilTag 2 的重点改进包括：

  • 重新设计 tag detector；
  • 相比原始 AprilTag，提高检测率；
  • 减少 false positives；
  • 降低计算时间；
  • 在小图像上表现更好，因此可以使用降采样图像来大幅提升速度；
  • tag coding scheme 保持不变，继续保留原有编码系统的抗误检能力。

工程上，这意味着 AprilTag 不只是“能识别”，而是更适合实时机器人系统。

3.3 Flexible Layouts for Fiducial Tags, IROS 2019

2019 年 IROS 的工作进一步扩展了 fiducial tag 的布局形式。传统 tag 多为正方形，而该论文提出 flexible tag layouts，可以支持圆形、环形或其他形状。

论文中的几个重要点：

  • flexible layout 可提升标准方形 tag 的数据密度；
  • 检测器相比 AprilTag 2 和 ArUco 更快，并有更高 recall，同时保持 precision；
  • 该工作曾入围 Best Student Paper 和 Best Application Paper finalist。

对机器人应用来说，这说明视觉标识并不一定只能是传统黑白方块，它也可以根据安装空间、外观设计和识别要求进行布局优化。

四、与 QR Code / ARToolKit 的区别

AprilTag 和 QR Code 都是二维条码，但设计目标不同。

对比项 QR Code AprilTag
主要目标 存储和读取信息 稳定识别与精确定位
数据容量 较大 很小，通常 4–12 bit 量级
机器人位姿估计 不是核心目标 核心目标之一
远距离/斜视角检测 取决于实现和尺寸 专门面向鲁棒检测设计
典型应用 链接、文本、支付、资产编码 机器人定位、标定、AR、实验基准

ARToolKit 与 AprilTag 的目标更接近，都是视觉标识定位系统。但 AprilTag 论文中展示了其在检测率和精度上的优势，并且 AprilTag 具有开放、轻量、易集成的工程特点。

五、在自主回充中的典型用法

机器人自主回充通常可以分成几个阶段：

  1. 全局导航到充电桩附近；
  2. 进入局部搜索和粗定位；
  3. 识别 Dock 附近的视觉标识；
  4. 基于 tag 位姿估计 Dock 相对机器人/相机的位姿；
  5. 执行低速精对准；
  6. 完成触点接触、充电确认和状态切换。

在四足机器人或轮足机器人回充中，AprilTag 的优势尤其明显：

  • 低速近距离对准阶段可提供稳定参考；
  • 可以与激光、深度相机、里程计、IMU 融合；
  • 对环境纹理依赖低；
  • 便于调试，打印和替换成本低；
  • 可通过 tag ID 区分不同 Dock 或不同定位点。

六、工程部署建议

6.1 标签尺寸

标签越大，远距离检测越容易，位姿估计也通常更稳定。但尺寸太大会占用 Dock 外观和结构空间。工程上应根据相机分辨率、视场角、对接距离和安装空间综合确定。

建议做法：

  • 先确定机器人进入精对准阶段的期望识别距离；
  • 在该距离下保证 tag 在图像中有足够像素宽度；
  • 对不同光照、倾角、运动模糊进行实测；
  • 不要只按“能识别”定尺寸，要按“位姿稳定”定尺寸。

6.2 安装位置

Dock 上的 tag 应尽量满足：

  • 在机器人接近路径上不易被遮挡；
  • 与充电触点、机械导向结构有固定且可测量的几何关系；
  • 不放在强反光、强阴影或易磨损区域；
  • 对相机视角友好，避免极端斜视角；
  • 需要多个 tag 时，保证它们之间的空间关系可标定。

6.3 相机标定

AprilTag 位姿估计强依赖相机内参和畸变参数。如果内参不准，tag 检测仍可能成功，但位姿结果会有系统误差。

建议：

  • 使用固定焦距和固定分辨率；
  • 部署前完成相机内参标定；
  • 改变镜头、分辨率、裁剪、畸变矫正流程后重新验证；
  • 记录 camera → robot base 外参，并做闭环校验。

6.4 检测参数与滤波

实际机器人运行中，单帧 tag 位姿可能有抖动。可以考虑：

  • 多帧滤波；
  • 结合里程计/IMU 做状态估计；
  • 使用 tag 检测置信度、重投影误差或几何约束过滤异常值；
  • 对最终接触阶段设置低速、安全停止和重试逻辑。

6.5 不要把 AprilTag 当作唯一安全机制

AprilTag 是定位工具，不是完整安全系统。自主回充还需要：

  • 近距离避障；
  • 速度限制；
  • 接触检测；
  • 充电电气状态检测；
  • 失败退出策略；
  • 机械导向或容错设计。

尤其在真实 Dock 上，最终能否稳定充电，往往取决于视觉定位、运动控制、机械结构、电气触点和状态机共同设计。

小结

AprilTag 的核心优势不是“能编码多少信息”，而是“能让机器人稳定地找到一个已知坐标系”。

在自主回充、相机标定、工装定位、实验验证等任务中，它提供了一个低成本、开源、实时、可重复的视觉定位方案。真正落地时，重点不只是选一个 tag family，而是把标签尺寸、安装位置、相机标定、检测滤波、运动控制和安全状态机一起设计。
