四旋翼无人机采购记录（2026）

文章目录

这篇用于记录 2026 年组装一台 450 级四旋翼无人机的采购清单、用途和后续检查事项。主要目标是学习 Pixhawk / ArduPilot 的装机、调参、定点悬停与基础自动飞行。

一、总体目标

计划组装一台 450 级四旋翼，用于：

  • 学习 Pixhawk 6C 飞控安装与接线
  • 学习 ArduPilot / QGroundControl / Mission Planner 调参
  • 室外空旷环境下做基础悬停测试
  • 后续尝试 GPS Loiter 定点悬停

注意：这套配置不是室内小飞机。450 级机架、10 寸桨和 4S 电池推力较大，首次起飞和定点悬停应在室外空旷场地完成。

二、已购买 / 准备购买清单

2. 遥控链路

项目 型号 / 规格 状态 备注
遥控器 RadioMaster Pocket ELRS 2.4G 版 准备买 / 已加入购物车 需要确认是 ELRS 版，不要 CC2500 / 多协议版
接收机 RadioMaster RP1 / RP3 ELRS 2.4G 待补充确认 如果遥控器套餐不含接收机，需要单独购买

注意：

  • Pixhawk 推荐使用 ELRS 接收机的 CRSF 串口输出。
  • 不建议买 FrSky / FlySky / 915MHz / 老式 PWM 接收机。
  • 接收机通常接 Pixhawk 的 TELEM2 或其他 UART：TX 接 RX、RX 接 TX、5V 接 5V、GND 接 GND。

3. 机架

机架 X450 / 10 寸四轴机架 准备买 / 已加入购物车 比 X400 更适合 Pixhawk + GPS，空间更充裕

选择理由：

  • 450 级空间适合安装 Pixhawk、GPS、接收机、电池
  • 10 寸桨适合稳定悬停和教学调试
  • 相比更小机架，布线和维护更容易

  • 4S 5000mAh 比较适合 450 级入门悬停调试。
  • 电池插头优先 XT60。

三、还需要补充的小配件

这些东西不贵，但装机时很容易缺：

  • ELRS 接收机：如果遥控器套装不含，优先补 RadioMaster RP1 / RP3 ELRS 2.4G
  • 备用 1045 正反桨：至少 2–3 套
  • 电池绑带、魔术贴
  • 扎带、热缩管、电工胶布
  • 螺丝胶
  • GPS 支架
  • 蜂鸣器 / 安全开关：如果 Pixhawk 套装没带，需要补
  • XT60 插头、硅胶线、转接线若干

四、接线规划

Pixhawk 6C 基本接线

设备 Pixhawk 端口 说明
PM07 电源模块 POWER1 给飞控供电并检测电压 / 电流
GPS / 罗盘 GPS1 / I2C GPS 箭头朝机头，尽量远离电源线和电调
数传模块 TELEM1 可选，地面站遥测使用
ELRS 接收机 TELEM2 或空闲 UART 使用 CRSF 协议
电调信号线 MAIN OUT 1–4 对应四个电机输出
安全开关 SAFETY 如果有安全开关则接入
蜂鸣器 BUZZER 方便找机和提示状态

ArduPilot Quad X 电机顺序

常见 Quad X 电机编号：

编号 位置 旋转方向
1 右前 逆时针 CCW
2 左后 逆时针 CCW
3 左前 顺时针 CW
4 右后 顺时针 CW

调试阶段必须先不装桨，通过地面站电机测试确认编号和转向。

五、调试顺序

  1. 组装机架、电机、电调，但先不要安装螺旋桨
  2. 安装 Pixhawk，箭头朝机头，尽量位于机架中心
  3. 安装 GPS 支架，GPS 箭头朝机头，远离电调和大电流线
  4. 接好 PM07、电调信号线、接收机、GPS
  5. 电脑连接 Pixhawk，刷 ArduCopter 固件
  6. 选择机架类型：Quad X
  7. 校准加速度计、罗盘、遥控器
  8. 设置 ELRS / CRSF 接收机输入
  9. 设置 failsafe 失控保护
  10. 不装桨做电机测试，确认编号和方向
  11. 室外空旷场地首次试飞，先 Stabilize / AltHold，再尝试 Loiter

六、安全原则

  • 调试、刷机、电机测试时绝对不要装桨
  • 第一次起飞不要在室内、楼道、客厅、车旁或人群附近
  • 室内 GPS 信号差，不适合做 Loiter 定点悬停
  • Loiter 需要 GPS 卫星数量足够、HDOP 良好、罗盘正常、震动较小
  • 可通过 MOT_THST_MAX 限制最大推力，但不能把它当作室内安全保障
  • 首飞建议低风、空旷、离地 0.5–1 米短时间悬停测试
