\begin{abstract}
本工程将一份中文技术文档拆成结构、数学、图表和参考文献四个部分。
公式、图片与书目都有可编辑的源文件；通过修改内容观察自动编号与版面的变化，
比记忆孤立命令更容易掌握排版规则。这里的机器人关节数据为教学构造数据，
不代表实际测量或控制器性能。
\end{abstract}
